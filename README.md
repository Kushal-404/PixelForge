# 🎨 PixelForge

A premium, sleek, dark-mode pixel art drawing web application. Built with a stunning "Midnight Monochrome" aesthetic, PixelForge gives you a distraction-free, highly responsive environment to create pixel art directly in your browser.

## ✨ Features

* **Customizable Canvas:** Set your own grid size (e.g., 8x8, 16x16, 32x32) or enter custom dimensions.
* **Essential Tools:** Pen, Eraser, Fill (Bucket), and Clear Canvas functionality.
* **Advanced Viewport:** Zoom in/out, pan across the canvas, and draw on a crisp, high-contrast checkerboard grid.
* **Color Palette:** Select from a preset vibrant neon palette or use the custom color picker.
* **Premium UI/UX:** Dark mode aesthetic with floating toolbars, responsive sidebars, and elevated canvas framing so your art always pops.

## 🚀 Tech Stack

* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom CSS variables, Flexbox/Grid, advanced conic-gradients for the canvas, and responsive design.
* **Vanilla JavaScript:** Core drawing logic, canvas manipulation, and tool state management.

## 🛠️ How to Run

Since this is a lightweight, front-end-only application, no complex build tools or servers are required!

1. Clone or download this repository to your local machine.
2. Open the folder and double-click the `index.html` file to open it in any modern web browser.
3. Start drawing!

## 🎮 Usage Guide

* **Draw:** Select the Pen tool, pick a color, and click or drag on the canvas to paint.
* **Pan:** Hold the `Spacebar` + drag your mouse to move around the canvas workspace.
* **Zoom:** Scroll your mouse wheel or use the `+` / `-` buttons on the floating toolbar above the canvas.
* **Change Grid:** Enter new width/height dimensions in the left sidebar and click "Generate grid" to start a fresh canvas.
